RUN RECORD
A SMALL, REPRODUCIBLE START

Welcome to your local lab.

TrainLab executes trusted experiment recipes and keeps their results together. Start from the TrainLab package directory:

python -m pip install -e .
trainlab run examples/linear.json
trainlab run examples/mean.json
trainlab serve --experiments examples
  1. Declare the experiment. Keep a JSON recipe beside its code and inputs. Declare every source file and the frozen split.
  2. Write the results. Your command writes metrics.json and declared artifacts into TRAINLAB_OUTPUT_DIR. Use TRAINLAB_SEED to seed your framework.
  3. Compare with context. Select two or more runs. TrainLab flags mismatched inputs, seeds, splits, metric definitions, or declared budgets.

The included demos use constructed data. Commands run as your local user. Register only recipes you trust; keep secrets out of commands, logs, and artifacts. The dashboard stays on loopback.
