# grilling
Maintain the highest-leverage unresolved decision frontier. For each item state the decision, evidence-backed recommendation, real alternative, dependencies, and consequences. Ask only what requires user judgment/private knowledge/authority. Persist resolved choices in durable project artifacts. Stop when uncertainty no longer blocks a coherent specification.
