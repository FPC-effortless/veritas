# diagnosing-bugs
Reconstruct the failing context. Build the smallest reliable reproduction before explaining causes. Rank falsifiable hypotheses; change one causal variable at a time. Fix the cause and add a regression test at a stable seam. For Veritas, test hidden/public state separation, replay, verifier semantics, leakage, and native-artifact/state agreement when relevant. Run the applicable verification ladder.
