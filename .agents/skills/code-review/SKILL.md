# code-review
Review separately: (1) correctness/maintainability, (2) task/spec compliance, (3) security/privacy, (4) architecture/invariants, (5) verification evidence. For Veritas add (6) benchmark/scientific validity, (7) frontier-utility evidence when claimed, (8) leakage/contamination/exploit resistance, and (9) release/private-artifact safety. A pass on one axis cannot cancel a failure on another. Cite concrete file/hunk evidence.
