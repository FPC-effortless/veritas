# writing-for-agents
State when the instruction applies, authoritative context, required inputs, allowed/forbidden actions, procedure, expected outputs/evidence, done/stop conditions, and escalation boundary. Prefer pointers to canonical sources over duplicated rules. Keep one source of truth per rule. Make instructions tool-agnostic unless a tool is genuinely required.
