# to-tickets
Each ticket must define outcome, prerequisites, owned files/surfaces, non-goals, falsifier/tests, evidence, verification, and authority constraints. Prefer observable vertical slices. If parallel agents are active, assign non-overlapping file ownership explicitly. Separate implementation-complete tickets from qualification/evidence tickets when they require different workflows.
