# research
Start with the question and decision relevance. Prefer repository code/canonical docs for project facts, then first-party docs, original papers/standards/datasets/source repos, then direct experiments. Separate observations, inferences, assumptions, and unknowns. For fast-changing facts verify recency. For Veritas scientific claims compare against the actual qualification contract and avoid extrapolating beyond the evidence.
