# grill-with-docs
Research facts yourself. Ask the user only for choices, private knowledge, or authority. Surface the highest-leverage unresolved decision, recommendation, countercase, and evidence that would change the recommendation. Check collisions with repository invariants/overlay. Persist stable decisions in a spec/ADR, not chat memory. Route to `to-spec` once implementation-level uncertainty remains.
