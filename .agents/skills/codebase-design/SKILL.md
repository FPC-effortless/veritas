# codebase-design
Evaluate interface cost versus complexity hidden. Prefer stable ports/adapters, narrow composition roots, localized invariants, and public seams testable without internal knowledge. Keep policy separate from mechanism. In Veritas preserve verifier independence, public/private separation, deterministic reconstruction/replay promises, and versioned environment contracts.
