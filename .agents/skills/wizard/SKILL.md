# wizard
Use only when the agent cannot legitimately perform the step. Explain purpose, hide secrets, never print/commit credentials, prefer official CLIs/APIs, confirm irreversible actions, validate each step, and make reruns safe. For Veritas, never expose private benchmark keys/bundles or convert manual sealed-panel workflows into ordinary automation without explicit authorization.
