# ask-matt
Read `AGENTS.md`, the universal contract, the repo overlay, active issue/spec, and relevant repository state. Classify the task. Route: facts→research; decisions→grilling; ambiguity→wayfinder; settled work→to-spec/to-tickets; bug→diagnosing-bugs; implementation→implement+tdd; general review→code-review; over-engineering diff→ponytail-review; repo-wide bloat→ponytail-audit; deliberate simplification ledger→ponytail-debt; handoff→handoff. The Ponytail minimality ladder is inherited on every coding route. Never route around local safety, privacy, branch ownership, scientific, or release constraints.
