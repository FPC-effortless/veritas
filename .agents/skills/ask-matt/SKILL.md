# ask-matt
Read `AGENTS.md`, the universal contract, the repo overlay, active issue/spec, and relevant repository state. Classify the task. Route: facts→research; decisions→grilling; ambiguity→wayfinder; settled work→to-spec/to-tickets; bug→diagnosing-bugs; implementation→implement+tdd; review→code-review; handoff→handoff. Never route around local safety, privacy, branch ownership, scientific, or release constraints.
