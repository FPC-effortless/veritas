# ponytail-help
Levels: `ponytail lite` = implement requested shape + name simpler option; `ponytail`/`ponytail full` = enforce ladder (default); `ponytail ultra` = deletion/YAGNI-first while preserving explicit requirements and safety. Deactivate the extra minimality preference with `stop ponytail`, `ponytail off`, or `normal mode`.

Skills: `ponytail` minimal solution selection; `ponytail-review` diff complexity pass; `ponytail-audit` whole-repo complexity pass; `ponytail-debt` deliberate-shortcut ledger; `ponytail-gain` methodology-labeled upstream benchmark card; `ponytail-help` this reference.

This repo-local fusion is tool/mode independent and does not require the upstream plugin. For upstream plugin compatibility only, Ponytail documents `PONYTAIL_DEFAULT_MODE` and `~/.config/ponytail/config.json` (Windows `%APPDATA%\ponytail\config.json`) with env > config > `full` resolution, plus host-specific slash/@ invocation and plugin update flows. Those host mechanics do not override this repository's `AGENTS.md` authority order.
