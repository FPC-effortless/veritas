# handoff
Record task/issue, branch/commit/PR, outcome/current state, decisions and sources, changed/owned files, tests/commands actually run, evidence/failures, unrun gates, privacy/authority status, unresolved risks, and exact recommended next action. Include deliberate minimality decisions that matter later, especially any `ponytail:` markers, their ceilings, and upgrade triggers; flag markers with no trigger as debt risk. Prefer repository/issue/PR links and durable artifacts over copying conversation prose. Redact secrets/private benchmark data.
