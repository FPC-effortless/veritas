# implement
Read governing context and active ownership rules. Define outcome/falsifier. Work on a task branch/worktree/sandbox. Use `tdd` or the task-appropriate falsifier loop. Make the smallest coherent change. Run targeted then broader verification. Capture evidence and unrun gates. Run `code-review`. Open/propose a PR. Do not merge/deploy/release or trigger expensive/manual workflows unless authorized by the active task.
