# improve-codebase-architecture
Inspect dependency structure, hotspots, duplicated invariants, leaky interfaces, oversized composition roots, and unstable tests. Score proposals by leverage, semantic risk, migration cost, and testability. For Veritas preserve public/private oracle separation, verifier independence, deterministic replay, and qualification boundaries. Turn material refactors into separate specs/tickets.
