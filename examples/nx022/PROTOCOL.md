# NX-022 — Testing whether a repair channel follows a sensor intervention

On each seed, assign eight of sixteen addresses to a dependent channel. Continue the NX-021 persistent sensor faults. Before deployment, randomly override the primary sensor register six times per address while leaving the physical state unchanged. Classify as dependent if at least three of six consequences match the predicted effect of the injected value. Compare always confirmed repair, always veto, detected routing, a sham (register unchanged), and oracle routing on identical deployment events. Detected dependence selects veto. Primary endpoint: detected routing beats the better fixed policy in mean all-address accuracy on each of two disjoint Forge panels (candidate ranges 13000–13319 and 14000–14319), with balanced detection accuracy at least 90%. Report paired intervals, write precision, audit cost and negative controls. In a second world the dependent channel shares an upstream fault but bypasses the manipulated register. No success criterion there. These policies do not receive dependence labels except the oracle control.

The superiority rule uses the smaller of the two paired mean gains (point estimates). Intervals are descriptive. The audit preserves the deployment fault roster. Deployment outcome draws are identical across topologies; only the audit's response to intervention changes.
