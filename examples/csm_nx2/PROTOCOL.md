# NX-011–020 prospective protocol

Use public Forge validation subjects from candidate seeds 9100–9419. Each seed is one paired replicate. The primary verifier sees only proposals and the outcomes of sensor queries. On separate calibration encounters, fit the probability that a repeated proposal will predict a future, separately sampled consequence. Calibration target is observed agreement with that consequence, which may itself be wrong. The simulator keeps the latent skill table for scoring only. Freeze admission at predicted agreement ≥0.75. Controls accept all, reject all, or require two agreements. Use independent and common-mode corruption, transition reversals, stable old keys and previously unseen keys. Retain denominator counts, right-censor unresolved repairs and report deployed-state accuracy separately from acceptance precision.

Primary decision rule on the independent-noise panel: pooled accepted-write precision ≥95%, committed key coverage ≥75%, old and new deployed accuracy each ≥85%. Reject-all must fail. Report these same criteria under common-mode noise. This is an engineering decision rule for the sampled worlds. No post-run changes to these thresholds.

Match addressable key and output space in NX-012. Learn conditional next-state maps from interaction for NX-014. For NX-015–018 acquire procedures from demonstrations or transitions, evaluate fresh inputs and depths 3, 4, 8, 16 and 32. Report where structure, tokenization, templates or primitive actions are supplied. Compare verification, composition, hierarchy and retrieval ablations. In NX-019 measure single-request latency including retrieval, execution and return, compilation time, memory and break-even reuse. Use twelve inference calls per acquisition for the requested cost weighting. NX-020 uses a single execution path through native components and measures intervention effects. Report per-seed data, independent replay and scientific status. Training and evaluation use distinct generated episodes. Reusing the same generator limits external validity.
