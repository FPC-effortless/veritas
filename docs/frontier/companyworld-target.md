# CompanyWorld as a Frontier Qualification target

CompanyWorld is a high-value future Frontier Qualification target because its persistent operational state, tools, permissions, interventions, and longitudinal execution can support richer capability and harness-difference measurements than a narrow classification benchmark.

No Frontier Qualification claim is made from architecture alone. CompanyWorld should remain `NOT_YET_FRONTIER_QUALIFIED` until the same explicit evidence contract is satisfied: policy-declared strong/frontier calibration, uncertainty-backed tier separation, comparable harness runs, failure-mode breadth, structural task-diversity evidence, separately scoped held-out/compositional transfer, training value, and regression controls.

The subsystem is intentionally environment-agnostic so CompanyWorld can consume it later without changes to CompanyWorld-owned code.
