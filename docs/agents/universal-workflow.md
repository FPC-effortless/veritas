# Universal coding workflow

## Routing

- unclear task/repo state -> `ask-matt` / repository reconstruction;
- unknown external fact -> `research`;
- unresolved decision -> `grill-with-docs` or `grill-me`;
- large ambiguous initiative -> `wayfinder`;
- settled direction -> `to-spec`;
- multi-session implementation -> `to-tickets`;
- implementation -> `implement` + `tdd`;
- bug -> `diagnosing-bugs`;
- incoming issue/PR -> `triage`;
- architecture health -> `improve-codebase-architecture`;
- vocabulary/boundaries -> `domain-modeling` + `codebase-design`;
- review -> `code-review`;
- human-only auth/secrets -> `wizard`;
- context transfer -> `handoff`.

## Universal review axes

Review material changes separately for:
1. correctness and maintainability;
2. task/spec compliance;
3. security/privacy;
4. architecture/invariants;
5. verification evidence.

Specialized repositories may add axes. Veritas adds scientific qualification, frontier utility, benchmark integrity, and release/privacy constraints.
