## Event definitions
- Conversation: substantive discussion with a qualified prospect.
- Workflow: concrete capability and evaluation target supplied.
- Agent access: usable endpoint or reproducible execution path supplied.
- Evaluation: scoped Veritas run completed.
- Useful failure: finding that materially changes understanding of the agent's capability or risk.
- Customer action: customer changes model, harness, permissions, workflow, deployment decision, or evaluation policy because of the result.
- Repeat: customer requests/completes another evaluation.
- Paid: paid qualification pilot starts.
- Renewal: recurring qualification continues.
- Referral: customer introduces another qualified prospect.
