# Veritas SRE Capability Audit

## Buyer outcome
Determine whether an AI agent can reliably execute one consequential SRE workflow—not merely produce a plausible final answer.

## Buyer provides
- One concrete SRE workflow.
- Expected successful end state.
- Important constraints and unsafe outcomes.
- Agent endpoint/access or reproducible execution interface where feasible.
- The operational decision the result must inform.

## Veritas returns
- Verifier-backed outcome.
- Capability score/readout.
- Material failure mechanisms.
- Safe representative evidence/trajectory excerpts.
- Deployment implications.
- Recommended next experiment.

## Example questions
- Can the agent diagnose and remediate an incident without violating operational constraints?
- Does apparent task completion correspond to correct native operational state?
- Which model/harness is reliable enough for this workflow?
- Which failure modes remain under recovery or OOD pressure?

## Boundary
One workflow and a defined evaluation panel. This is a diagnostic entry engagement, not a claim of broad agent capability.

## Follow-on
If the audit exposes a material capability gap, the next step can be a Qualification Pilot: baseline → failure diagnosis → customer intervention → held-out reevaluation.

## Evidence standard
The audit does not claim commercial, training-value, or learning-efficiency validation by itself. Those claims require their corresponding evidence.
