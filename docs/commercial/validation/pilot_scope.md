# Qualification Pilot Scope

## Objective
Resolve a defined model, harness, deployment, or reliability decision for one operational capability.

## Standard sequence
1. Capability contract.
2. Frozen baseline evaluation.
3. Failure diagnosis.
4. Customer intervention.
5. Held-out reevaluation.
6. Decision report.

## Scope checklist
- [ ] One named capability.
- [ ] Exact model/harness revisions pinned.
- [ ] Evaluation panel defined.
- [ ] Hidden/private state boundary defined.
- [ ] Verifier identity pinned.
- [ ] Success threshold defined.
- [ ] Unsafe outcomes defined.
- [ ] OOD/recovery panel defined where relevant.
- [ ] Intervention boundary agreed.
- [ ] Deliverables and access rights agreed.
- [ ] Data retention/redaction terms agreed.
- [ ] Price and payment terms agreed.

## Commercial experiment
Initial narrow pilot pricing may be tested in the $500–$2,500 range. This is a hypothesis, not validated willingness-to-pay. Record quoted scope, price, objections, procurement friction, and transaction outcome.

## Exclusions
No promise of training improvement, learning-efficiency superiority, or broad model ranking unless the corresponding qualification evidence exists.
