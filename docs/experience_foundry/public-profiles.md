# Bounded public structural profiles (PUB-PROFILE-001 / #464)

This is a provider extension for deterministic **public synthetic implementation
conformance**, not SYN-001 completion, a measured model deficit, a model screen,
training usefulness, scientific qualification or release authority. No model,
trainer, protected panel, external service or paid workflow runs here.

## Closed profiles

`PublicTrainingRecorder(root)` retains the exact original v1 seed-73 first
financial TRAIN fixture, metadata, acceptance gates and trainer projection.
`public_training_fixture()` is unchanged. Its iterator consumes one TRAIN yield,
never a held-out case. Independent regression hashes pin the original case,
episode, capability, portable contract, public payload and trainer bytes.

Two explicit `profile_id` values enable recorder v2:

| Profile | Actual structural difference |
| --- | --- |
| `financial-ordered-v2` | Recalculation has a prior-successful-repair precondition and the task requires that action order. |
| `financial-ordered-context-v2` | The same dependency plus a public context record linked to the audited workbook object. |

The dependency is enforced by the existing runtime: premature recalculation is
blocked, charged and recorded. It is not an action-argument change or a metadata
claim. The context record uses Foundry `apply_mutation` with an explicit mapping
from its CompanyWorld-shaped record to `OperationalRecord`. The public objective
and constraints disclose the dependency, and both profiles explicitly identify
the task as synthetic. No additional formula target, action type, native-engine
behavior or canonical verifier semantics is introduced. The native financial
engine supports one formula target; this extension does not imply multi-formula
support or a measured increase in difficulty.

Profiles are a finite allowlist, not an episode/plugin registration API. Callers
cannot supply arbitrary seeds, task objects, oracle edits or generation settings.
The original capability contract is retained as a declared task association;
this is not empirical evidence of agent competence or general causal structure.

## Regeneration, provenance and privacy

The recorder binds the exact generated episode, full capability and portable
contract, native receipt, actual actions, submission, cost, installed runtime
digest and recorder version. V2 companion metadata also binds the profile ID,
generator-source digest, configuration digest, parent fixture digest and actual
dependency/evidence structure digest. Source hashes describe installed producer
bytes, not external authentication or cryptographic execution attestation.

Both validation-only and successful-admission paths independently regenerate the
allowlisted profile. Recomputing caller hashes after modifying the episode,
profile metadata or contract does not replace this comparison. Fresh native
ActionEvents must also exactly reproduce each v2 companion act event, including
its success flag and cost. Fresh native
inspection uses retained artifact bytes; stale/caller-supplied verification
history cannot supply a cached PASS. Canonical unknown model, harness, runtime,
seed and split fields remain unknown; the private companion does not overwrite
them. Unsupported versions and profiles fail closed.

V2 source material remains the same deliberately public synthetic boundary as
v1. Counterfactual receipts, diagnostic/gap envelopes and #160 derivatives remain
evaluator-private, unqualified candidates. Public/buyer projections withhold
their evidence, and derivative `trainer_payload()` still refuses. No sealed or
held-out source is admitted, generated or traversed. Caller-provided frozen
exclusions are checked but do not prove complete contamination clearance.

## Complete deterministic replay

Counterfactual receipt v1 and its failed-untouched-call rejection are preserved.
Receipt v2 is bound to recorder v2 and an independently regenerated public-at-cut
profile. It executes every admitted native action in the prefix and suffix,
including blocked calls. Foundry's existing counterfactual executor still
executes the divergence; its success-only prefix helper is not used to skip v2
failures. Unknown methods, noncontiguous events, unsupported interventions and
unrecorded exceptions do not become successful receipts.

Baseline, alternative and independent alternative repeat each use a distinct new
artifact workspace. Baseline semantic equality with the source and alternative
repeatability remain mandatory. V2 semantic fingerprints include the exact
profile contract so different task structures cannot become aliases merely
because an action sequence has the same final state. Validation freshly checks
all four executions and rebuilds the receipt, bindings, deltas and statuses.

Blocked calls consume their original runtime budget and remain in violation
evidence. For example, repairing the first failed action can eliminate a blocked
recalculation suffix in the alternative. Conversely, a blocked required action
in an untouched prefix remains a process violation even if all final targets are
later restored. Such an alternative is not a clean recovery and is not admitted
as a successful SFT example. No success gate is relaxed for replay convenience.
